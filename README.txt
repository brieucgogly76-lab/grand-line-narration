# Grand Line Narration — Web version

Cette version contient les fichiers Web extraits de l'APK et une compatibilité
de stockage navigateur basée sur localStorage.

## Lancer le jeu
Ouvrir `index.html` dans un navigateur moderne.

## iPhone
Pour une utilisation confortable sur iPhone, héberger le dossier sur un serveur
Web puis ouvrir l'adresse dans Safari. Une fois le jeu ouvert, utiliser
« Partager » > « Sur l'écran d'accueil » pour créer une icône.

Remarque : cette adaptation ne transforme pas l'application Android en application
iOS native. Les fonctions Android éventuelles (publicités, intégrations système,
etc.) ne sont pas garanties.
